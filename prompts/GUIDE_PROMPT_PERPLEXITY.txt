================================================================================
⚠️ POINTS DE VIGILANCE
================================================================================

1. CHAMP source
---------------
❌ ERREUR : mettre "LinkedIn", "WTTJ", etc.
✅ CORRECT : toujours "Perplexity"

Le champ plateforme_source contient la vraie source (LinkedIn, WTTJ, etc.)


2. CHAMP status
---------------
❌ ERREUR : mettre "active", "validated", etc.
✅ CORRECT : toujours "new"

Le statut sera mis à jour automatiquement par le système d'historisation


3. CHAMP priorite_ville
------------------------
❌ ERREUR : texte ("Rennes"), autre numérotation
✅ CORRECT : 
- Rennes = 1
- Nantes = 2
- Paris = 3


4. FORMAT DES DATES
-------------------
❌ ERREUR : 
- date_creation: "2026-02-05" (format ISO)
- first_seen: "05/02/2026" (format français)

✅ CORRECT :
- date_creation: "05/02/2026" (format français DD/MM/YYYY)
- first_seen: "2026-02-07" (format ISO YYYY-MM-DD)


5. CHAMP id
-----------
❌ ERREUR : 
- Espaces : "doctolib alternance digital paris"
- Majuscules : "Doctolib_AlternanceDigital_Paris"

✅ CORRECT :
- Lowercase sans espaces : "doctolib_alternancedigital_paris"
- Format : entreprise_titre_ville


6. NULL vs STRING
-----------------
❌ ERREUR : "null" (string)
✅ CORRECT : null (sans guillemets)

Exemples :
- "date_expiration": null ✅
- "duree_contrat": null ✅
- "date_expiration": "null" ❌
