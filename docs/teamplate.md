# Template Visuel - Veille Alternances

## Structure d'une offre
- Badge NEW/Active + Source (LBA/Perplexity)
- Titre + Entreprise + Ville
- Description complète (2-3 lignes)
- Compétences (badges verts)
- Détails alternance (contrat, durée, début)
- Détails source (créée, expire, via)
- Bouton "Postuler"
