# Template Visuel - Veille Alternances

## Structure d'une offre (à NE PAS modifier)
- En-tête : Badge NEW/Active + Source (LBA/Perplexity)
- Titre + Entreprise + Ville
- **Description complète** (2-3 lignes visibles sans cliquer)
- **Compétences** : badges verts (SEO, SEA/Paid Media, Content Marketing, Analytics)
- **Détails ALTERNANCE** : Contrat, Durée, Début
- **Détails SOURCE** : Créée, Expire, Via
- Bouton "Postuler"
