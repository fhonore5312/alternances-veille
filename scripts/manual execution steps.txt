Sorties écran manquantes
Les scripts utilisent printf mais les sorties sont tronquées dans ton terminal. Pour les récupérer proprement, redirige vers un fichier log :

powershell
python -m scripts.scraper_lba --all-tracks 2>&1 | Tee-Object -FilePath logs\run_$(Get-Date -f 'yyyyMMdd_HHmm').log



# Pour tout lancer d'un coup
powershell
python main_flow.py 2>&1 | Tee-Object -FilePath logs\run_$(Get-Date -f 'yyyyMMdd_HHmm').log
Le main_flow.py logue déjà dans logs/flow_YYYYMMDD_HHMMSS.log automatiquement, donc tu auras toujours une trace même sans Tee-Object.
